# Последний Заказ — NightShift

**0.10.0-rc.1 · общий кандидат на релиз.**

В этой сборке объединены Endless, 30 миссий, 20 головоломок, прогресс, PWA, Telegram-адаптер и код серверного рейтинга. **Это не подтверждённый финальный релиз:** живые Supabase/Telegram, реальные браузеры и телефоны ещё не проверены. Phaser/Vite не внедрены; клиент использует Canvas 2D + TypeScript.

## Быстрый запуск

Распакуйте архив, перейдите в `nightshift` и выполните:

```bash
node scripts/serve.mjs
```

Откройте `http://localhost:4173/`. Нужен Node.js 22 или новее. Устанавливать зависимости для запуска готовой игры не требуется. Сервер слушает локальный компьютер. HTML двойным кликом не запускайте: ES-модулям нужен HTTP.

## Что доступно

- **Endless:** сохранённый режим MVP-3 без лимита и проигрыша; пауза, настройки, музыка, эффекты и статистика.
- **Миссии:** 30 уровней в трёх главах, JSON-каталог, цели по очкам, предметам, препятствиям и доставке; лимит ходов, звёзды, повтор и следующий уровень. У каждого уровня есть автоматически проверенное решение.
- **Препятствия:** лёд в один/два слоя, коробки, соус, подносы, цепи. Коробки и подносы занимают клетки и разделяют падение; цепи блокируют обмен и падение в своей клетке. Число на препятствии обозначает оставшуюся прочность. Пакеты ↓ опускаются к нижнему краю.
- **Головоломки:** 20 детерминированных задач с лимитами от одного до четырёх ходов, повтор, подсказка; бустеры запрещены. Сохранённые решения подтверждают решаемость, уникальность решения не заявляется.
- **Прогресс:** XP, уровень, звёзды, открытие следующих миссий/глав, крышки, инвентарь, достижения, ежедневная награда, магазин за игровые крышки. Повтор одного результата не выдаёт награду снова.
- **Бустеры миссий:** открывашка, перекрашивание, перемешивание; стартовые ракета, бомба, молния. Стартовые применяются только до первого хода; при повторе потраченный инвентарь не возвращается.
- **Хранение:** IndexedDB с синхронным localStorage-checkpoint для миссий; отдельная IndexedDB-копия Endless. Стабильное конечное поле сохраняется до воспроизведения анимаций. Прогресс локальный, не синхронизируется между устройствами.
- **PWA:** manifest, PNG-иконки, precache всей игры, установка и подтверждаемое обновление. Офлайн возможен после успешной первой загрузки и завершения установки кэша. Service worker изолирован путём репозитория и не удаляет кэши других игр на github.io.
- **Telegram:** загрузка официального SDK в Telegram-контексте, viewport/safe areas, BackButton, haptics, пауза при деактивации, серверная проверка initData. Связь с реальным ботом пока не настроена.
- **Рейтинг:** автономная тренировка на 50 ходов; онлайн-клиент и Node.js/Supabase backend с проверкой replay, RLS, ограничениями запросов, дневным/недельным/месячным рейтингом, TOP-100 и соседями игрока. По умолчанию `apiBase` пуст, поэтому онлайн-таблица честно сообщает о недоступности.
- **Графика и обучение:** оригинальный фон ночного заведения, портрет Риты, растровый атлас шести предметов, эффекты спецэлементов, музыка, диалоги трёх глав и повторяемое обучение. Мастерская 11 комбинаций по-прежнему доступна в `lab.html`.

## Управление

Два нажатия на соседние клетки или свайп. На клавиатуре — стрелки, пробел/Enter для выбора. Escape открывает паузу в Endless и миссиях. В миссиях кнопка «?» повторяет обучение. Бустер сначала выбирается кнопкой, затем указывается клетка. Перекрашивание запрашивает тип 1–6.

Во время анимации ходы заблокированы. Пауза замораживает анимации. При паузе посреди каскада выход/перезапуск могут оставаться недоступными до его завершения после возобновления. Сохранённое поле уже содержит полный результат хода.

Настройки русского/английского, движения, символов и звука находятся в основном меню. Новые разделы используют эти настройки при открытии; экран рейтинга и отдельные служебные подписи двуязычные. Полная редактура локализации ещё требуется.

## GitHub Pages

1. Загрузите **содержимое `nightshift`** в корень репозитория, включая `.github`.
2. В Settings → Pages → Source выберите GitHub Actions.
3. Запустите workflow **Publish NightShift to GitHub Pages**.

Workflow собирает и проверяет проект, затем публикует только `dist/`. Исходники, backend и секреты не публикуются как часть этого артефакта. Пути ресурсов относительные, включая PWA scope для `username.github.io/repository/`.

Для публикации без сборки можно разместить **содержимое готового `dist/`** в корне отдельного Pages-репозитория. Файл `.nojekyll` включён. Не загружайте просто ZIP как единственный файл сайта.

Опубликовано и проверено на реальном GitHub Pages: [dorokhin95.github.io/nightshift](https://dorokhin95.github.io/nightshift/). Все ресурсы, manifest и service worker (scope изолирован путём `/nightshift/`) загружаются корректно по опубликованному URL; PWA-установка регистрируется и активируется. Проверено эмуляцией мобильного вьюпорта (375×812, свайп/тап) и симуляцией Telegram-контекста (`tgWebAppData` + официальный `telegram-web-app.js`) в браузере — без ошибок в консоли. Проверка на физическом телефоне и в реальном Telegram-клиенте с настоящим ботом остаётся открытой.

## Подключить настоящий рейтинг

См. `backend/README.md`: схема Supabase, серверные переменные, Telegram-бот, отдельный HTTPS API. Ключи хранятся только на сервере. В `public/runtime-config.json` указывается только URL API, затем выполняется сборка.

Supabase-проект и бот не были созданы или изменены; API не развёрнут. В архиве подготовлены `schema.sql`, `server.mjs`, проверка подписи, `.env.example` и Dockerfile. Для работы через интеграцию ассистента нужно установить и подключить Supabase, затем выбрать проект.

## Разработка и проверки

```bash
npm ci
npm run check
npm run dev
npm run levels
```

`npm ci` требует npm registry. Генератор уровней воспроизводимо создаёт каталоги и контрольные решения. На готовой сборке без установки зависимостей:

```bash
node --test tests/unit/*.test.mjs tests/campaign/*.test.mjs
node scripts/verify-dist.mjs
```

**141 автоматический тест пройден.** Проверены ядро, все спецкомбинации, решения всех 50 уровней, восстановления, награды, подписи/токены, replay, обработчики экранов в имитации DOM и изоляция офлайн-кэша. TypeScript и ESLint проходят.

**Не выполнены:** реальная браузерная/мобильная QA, iPhone PWA, звук и жесты на устройствах, живой Telegram, исполнение SQL/RLS/RPC на Supabase, серверная интеграция после развёртывания и перенос на Phaser/Vite. Chromium отсутствует в рабочей среде. Эти пункты явно остаются открытыми в ROADMAP.md.

## Файлы

- `src/game/core` — неизменённые правила Endless/ranked `mvp2-v1`.
- `src/campaign` — отдельная детерминированная механика уровней и прогресс.
- `src/app` — основной клиент, музыка, PWA/Telegram и рейтинг.
- `public/data` — 30 миссий, 20 головоломок и контрольные решения.
- `public/art` — фон, Рита и атлас, созданные ImageGen для проекта.
- `backend` — сервер, схема и инструкции подключения.
- `dist` — готовая статическая игра.
- `docs/TEST-REPORT.md` — проверенное и непроверенное; `public/about.html` — сведения о данных и авторах.

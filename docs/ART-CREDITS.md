# Ресурсы изображений

Созданы встроенным ImageGen для NightShift и включены в public/art. Пользовательских фотографий или внешних лицензируемых персонажей не использовано.

- diner.png: широкий кинематографичный интерьер ночного diner/bar, глубокие teal-тени и amber-свет, тёмная пустая левая часть под UI, детальные стойка и диваны справа, без текста и людей.
- rita.png: взрослая механик/бармен Рита, короткие рыжие волосы, teal-куртка, уверенная доброжелательная улыбка, живописный игровой портрет на фоне заведения, без текста.
- food-atlas.png: сетка 3×2, предметы по порядку: бутылка, пицца, бургер / стакан, картофель, крендель; подробные стилизованные предметы на navy-фоне, без подписей. Canvas использует шесть равных областей атласа.

Функциональные иконки препятствий и спецэлементов продолжают существующую Canvas-систему. PWA-иконки — растеризация простого геометрического значка молнии. Музыка/SFX синтезируются кодом, внешние аудиофайлы не используются.

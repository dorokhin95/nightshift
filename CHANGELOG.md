## Подготовка к публикации — 2026-09-11

- Исправлен `scripts/build-demo.mjs`: рекурсивное копирование `public/` → `dist/` через `fs.cpSync(...,{recursive:true})` приводило к падению Node.js (STATUS_STACK_BUFFER_OVERRUN) на путях с не-ASCII символами; заменено на ручной рекурсивный обход директорий.
- `about.html`: добавлен `viewport-fit=cover` в meta viewport для единообразия с остальными экранами (safe-area на iPhone).
- `npm audit fix`: устранены 2 high-severity уязвимости в транзитивных dev-зависимостях (brace-expansion, js-yaml); рантайм игры не затронут.
- Проверено вручную в браузере: десктоп (1024×768), мобильный (375×812) и симулированный Telegram Mini App контекст (`tgWebAppData`, реальный `telegram-web-app.js` с CDN) — меню, Endless (тап и свайп), кампания/обучение, диалоги, PWA install-кнопка. Ошибок в консоли не обнаружено.
- `npm run check` (typecheck + lint + 141 тестов + build + verify-dist) проходит полностью.

# Состояние этапов · 0.10.0-rc.1

| Этап | Реализовано | Что остаётся |
|---|---|---|
| MVP-1 | Детерминированное ядро, каскады, сохранения, replay | — |
| MVP-2 | Все спецэлементы/комбинации, мастерская | Проверка звука/жестов на устройствах |
| MVP-3 | Меню, Endless, пауза, настройки, итоги | Phaser/Vite, браузерная QA |
| MVP-4 | 30 миссий, все пять препятствий, цели, доставка, звёзды, JSON loader | Игровое тестирование людьми и балансировка |
| MVP-5 | 20 задач с фиксированным seed, лимитом, повтором, подсказкой и проверенным решением | Игровое тестирование людьми |
| MVP-6 | IndexedDB/checkpoint, XP, достижения, крышки, инвентарь, награды, автосохранение | Проверка IndexedDB в реальных браузерах |
| MVP-7 | Manifest, иконки, офлайн-кэш, установка, обновление, GitHub Pages scope | Проверка установки/обновления на iPhone/Android |
| MVP-8 | Telegram SDK adapter, viewport, safe areas, BackButton, haptics, серверная HMAC-проверка | Настроить реального бота и проверить Mini App |
| MVP-9 | Node API, SQL/RLS/RPC Supabase, сессии, replay, лимиты, рейтинги | Подключить проект, применить/проверить SQL, развернуть API, пройти end-to-end |
| MVP-10 | Растровые предметы, интерьер, Рита, обучение, диалоги глав, музыка/SFX, переходы, 30/20 уровней | Финальная QA/балансировка, редактура локализации, дополнительные сюжетные персонажи по полному художественному ТЗ |

Все этапы имеют реализацию в архиве, но **не все приняты и не все подключены**. Маркировка RC выбрана намеренно: готовность к публичному финальному релизу не подтверждена.

Проверено 141 автоматическим тестом. Реального браузера Chromium и iPhone/Android в среде нет; живая Supabase/Telegram-интеграция отсутствует. Исходное ТЗ в SPEC.md сохранено.

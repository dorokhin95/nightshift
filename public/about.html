Данные / Privacy

Endless, миссии, настройки и награды сохраняются на этом устройстве в localStorage и IndexedDB. Аналитика, реклама и платежи не подключены. Сброс прогресса миссий доступен в разделе наград; полное удаление локальных данных — через настройки сайта в браузере.

При входе в онлайн-рейтинг сервер получает проверяемые Telegram initData, Telegram ID и имя. Для рейтинга хранятся игровые сессии, ходы, счёт и даты; имя и результат доступны участникам рейтинга. IP используется в хешированном виде для ограничения частоты запросов. Сервер не подключён в стандартном архиве; тренировка ничего ему не отправляет.

Local play is stored on this device. No analytics, ads or payments. Online ranked play sends verified Telegram identity and game moves to the configured server; the nickname and verified score appear on the leaderboard. The default release has no ranking server configured.

Авторы и ресурсы / Credits

Оригинальные изображения: интерьер NightShift, портрет Риты и атлас предметов — созданы с помощью ImageGen для этого проекта. Музыка и звуковые эффекты синтезируются программно через Web Audio. Игровая логика и интерфейс — TypeScript и Canvas. Сторонние CDN для обычной игры не нужны; Telegram SDK загружается только в Telegram-контексте.

Версия для проверки

Это release candidate. Реальные iPhone/Android, браузерная отрисовка, живая база Supabase и Telegram-бот ещё требуют проверки владельцем развёрнутой игры. Перенос на Phaser/Vite остаётся открытой технической задачей.
